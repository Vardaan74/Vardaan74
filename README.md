# Hi, I'm Vardaan

Business Technology Management student at UBC Sauder (Business Analytics). I build AI tools and automations for real workflows, starting with how people do the work today.

## TenderSense (Jan to Sep 2026)
An AI tool that helped construction contractors decide which government tenders to bid on. It read tender packages of up to 1,000 pages and produced a bid/no-bid briefing on eligibility, payment terms, penalties and hidden risks.

- **Pilot:** 3 firms, 70 live tenders. First review went from 2 days to under 30 minutes.
- **Stack:** TypeScript, Next.js, Supabase/PostgreSQL, Azure Document Intelligence (OCR), Claude API, Vercel. Built with Claude Code and Cursor.
- **Trust:** every finding opens the source PDF at the highlighted clause, code checks each quote against its page, and a second AI review pass catches errors before users see them.
- The code is private. Happy to walk through it.

## Automations for small businesses (2025)
- **Missed-call follow-up for a landscaping company:** Twilio, n8n and the Claude API texted missed callers and sorted replies into callbacks or booked appointments, with urgent cases sent to a person. 10 booked site visits and 4 jobs worth $8,400 in 6 weeks.
- **Prospecting pipeline for a commercial glass company:** Clay, Apollo, Smartlead and HubSpot. 320 companies narrowed to 185 qualified property managers, leading to 4 meetings and a first job.
